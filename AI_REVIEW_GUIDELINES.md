# Project Guidelines

## Tech Stack
- React
- Vite
- React Router
- Tailwind CSS

## Development Rules
- Build the project using React + Vite.
- Use React Router for all page/navigation routing.
- Use Tailwind CSS for styling.
- Use functional React components and hooks.
- Create reusable, modular components.
- Follow a clean and scalable folder structure.
- Avoid unnecessary dependencies and custom CSS.
- Keep the code clean, readable, and maintainable.
- Ensure the UI is fully responsive across mobile, tablet, and desktop.
- Follow basic accessibility best practices.
- Avoid console errors, warnings, unused code, and duplicated logic.

## AI Review Instructions
Before reviewing, inspect the entire project and compare it against the assessment requirements.

Review:
1. Requirement compliance
2. UI/UX and visual accuracy
3. React architecture
4. React Router implementation
5. Tailwind CSS usage
6. Responsiveness
7. Accessibility
8. Code quality and maintainability
9. Performance
10. Overall submission readiness

For every issue:
- Explain the problem briefly.
- Mention the relevant file/component.
- Give a practical fix.
- Mark severity: Critical / High / Medium / Low.

Do not suggest changes based only on personal preference. Prioritize requirements, functionality, UX, responsiveness, accessibility, and code quality.

## Final Review
Provide:
- Score out of 10
- Strengths
- Issues by severity
- Most important improvements
- Submission readiness
- Final verdict: `Ready to submit` / `Minor improvements` / `Significant improvements required`
